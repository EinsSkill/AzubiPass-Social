# Erweiterter Modus · Übergabepaket

Beginne mit [CLAUDE_UEBERGABE.md](CLAUDE_UEBERGABE.md). Dort stehen Auftrag, Bedienung, technische Anschlussstellen und drei vollständige Mustertexte.

| Datei | Zweck |
|---|---|
| CLAUDE_UEBERGABE.md | Zusammenhängende, direkt lesbare Spezifikation und Muster |
| abschnittsvertrag.entwurf.json | Drei Muster als strukturierter Datenvertragsentwurf; erst nach Rendereranpassung übernehmen |
| redaktionsplan-160-kapitel.csv | Vollständiger Arbeitsbestand mit Berufszuordnung, Abschnitts-IDs, Profilen und Prioritäten |
| abnahme.json | 26 Verhaltensabnahmen; nicht als bereits bestandene Tests ausgeben |
| vorbereitungsbelege.json | Umfang, Quellstand und tatsächlich durchgeführte Dokument-/Referenz-/Rechenprüfungen |

Die begleitenden Auditdokumente im Paket liefern den fachlichen Korrekturkontext. Haupttexte sind Einfügevorlagen, übriger Bestand ist ein Redaktionsplan. Anwendungscode wurde in dieser Vorbereitung nicht geändert.
