## Kleine fachliche Präzisierungen am gemeinsam genutzten Alttext

Diese Präzisierungen betreffen beide Ansichten und dürfen nicht nur im neuen Text anders behauptet werden:

**LF10 K5 b1, vorhandener `merke`-Block:** Die pauschale Schlussfolgerung „positiver Deckungsbeitrag heißt: Verkauf lohnt sich kurzfristig“ begrenzen. Vorschlag: „Deckungsbeitrag = Erlös − variable Kosten. Ein positiver Beitrag hilft, unverändert anfallende Fixkosten zu decken. Ob ein Auftrag vorteilhaft ist, hängt zusätzlich von Kapazität, weiteren vermeidbaren Kosten und Alternativen ab.“ Die bestehende Kartenkennung erhalten, Frage nur fachlich begründet präzisieren.

**LF10 K5 b1, vorhandener `achtung`-Block:** „Streicht man es, bleiben die Fixkosten trotzdem“ als Fallannahme, nicht allgemeine Wahrheit formulieren. Vorschlag: „Ein Produkt kann einen Vollkostenverlust zeigen und unter bestimmten Bedingungen trotzdem zur Deckung gemeinsamer Fixkosten beitragen. Wenn beim Streichen keine Fixkosten entfallen und keine bessere Verwendung knapper Kapazität möglich ist, geht sein positiver Deckungsbeitrag verloren. Welche Kosten tatsächlich entfallen, muss der Fall zeigen.“

**LF7 K3 c2, vorhandene Tabelle:** „Geschlossene Fragen lassen nur ja oder nein zu“ als vereinfachten Unterfall kennzeichnen: „Ja/Nein-Fragen sind eine häufige Form geschlossener Fragen. Geschlossene Fragen begrenzen die Antwortmöglichkeiten.“ „Am Anfang würgen sie ab“ durch kontextbezogene Formulierung ersetzen: „Beim noch unklaren Problem können sie vorschnell verengen; zum Prüfen konkreter Angaben können sie auch früh sinnvoll sein.“ Die bestehende Frage im Check bleibt im vorgegebenen unklaren Problemfall richtig.

Keine Aufgabenkennungen oder Punkte allein wegen dieser Präzisierung ändern. Notwendige Text-/Antwortkorrekturen und betroffene Regression nachvollziehbar berichten.
